# Bid Qualification Copilot

A small, working prototype of an internal AI copilot for bid qualification. It reviews a tender,
finds evidence only in documents the user is allowed to see, flags risky clauses, and registers the
bid in a (mock) CRM only after the right person has approved it.

> Independent portfolio project built on synthetic data. It is not affiliated with, and does not
> reproduce, any company's product or internal workflow.

**Status:** work in progress. See [docs/BUILD_LOG.md](docs/BUILD_LOG.md) for the step-by-step build.
